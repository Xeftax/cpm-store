# Roadmap

Plan by phases. **Rule**: a phase only starts when the previous one is
green (tests + clippy + fmt). Every phase has a verifiable exit criterion.

| Phase | Content                                                                                                                                                                                                                                                                                         | Exit criterion                                                | Status |
| ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- | ------ |
| 0     | Setup: workspace, CI, license, docs, AGENTS.md, embedded specs (+ QA vs official PDFs): 6 CPM V2_2 specs + `OMA-TS-REST_NetAPI_NMS-V1_0-20190528-C` (base of the REST binding, embedded 2026-11-08), SCR checklist                                                                              | `cargo build/test/clippy/fmt` green, repo committed           | ☑ done |
| 1     | `cpm-core`: NMS/CPM models + **ports** (`StoreBackend`, `MessageStorage`, `SyncStateStore` traits) + `SyncState` (serializable blob, D3) + objectId↔local id mapping. Golden tests from annexes B/C–H **extracted from the official PDF** (pdftotext). `cargo-deny` (licenses+advisories) in CI | golden tests with the JSON examples of [CPM-REST] annexes C–H | ☐      |
| 2     | `cpm-nms` base: HTTP transport (reqwest/rustls), auth (Bearer/Basic), boxes, folders CRUD/list/search                                                                                                                                                                                           | `wiremock` tests on `/nms/v1/base/{boxId}/folders...`         | ☐      |
| 3     | `cpm-nms` objects: CRUD + bulk + multipart payloads + flags                                                                                                                                                                                                                                     | `wiremock` tests + spec fixtures                              | ☐      |
| 4     | `cpm-nms` sync: subscriptions, notifications, `restartToken`/`lastModSeq`; `cpm-client`: first-time + steady-state, cache via traits                                                                                                                                                            | scenario: 2 mocked clients converge                           | ☐      |
| 5     | `cpm-msg`: parse/serialize CPIM (RFC 3862) + MIME multipart, CPM message ↔ Linphone conversation mapping                                                                                                                                                                                        | round-trip on spec examples                                   | ☐      |
| 6     | `cpm-ffi`: C API (cbindgen), CMake build in linphone-sdk, sample call                                                                                                                                                                                                                           | linphone-sdk compiles with the linked library                 | ☐      |
| 7     | Hardening: parsing fuzz (cargo-fuzz), perf, SCR conformance report, **IMAP adapter** (`cpm-imap`, implements `StoreBackend` on Message_Store V2_2)                                                                                                                                              | `docs/conformance.md` fully checked + `cpm-imap` compiles     | ☐      |
